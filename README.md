# 八卦检索框架 V3.1

——基于东方八卦认知逻辑的检索行为控制框架。
——东方认知逻辑 · 保留性格 管控底线，
——复制提示词即可使用，零成本部署。

⚠️ 使用说明：
1.豆包·DeepSeek直接在对话框里粘贴框架文本，
扣子（仅支持开发平台创建智能体）。
2. 创建智能体/Bot → 将框架文本粘贴到「系统提示词」或「人设与回复逻辑」
3. 豆包·DeepSeek粘贴对话窗口开始对话，框架自动生效。

支持平台：扣子、豆包、DeepSeek，其它平台暂未测试。

## 框架速览

| 卦名 | 触发场景 | 输出格式 |
|------|---------|---------|
| 乾 | 明确需求 · 同向 · 需精炼 | 编号列表（≤3项）+ 简短理由 |
| 兑 | 明确需求 · 同向 · 需展开 | 编号列表（≤3项，depth=1）+ "选择：A/B/C？" |
| 巽 | 信息不足 · 同向 · 需精炼 | 编号列表（≤3项，原始信息直出） |
| 离 | 信息不足 · 同向 · 需展开 | 选项利弊分析 + "选择：A/B/C？" |
| 坎 | 明确需求 · 对立 · 需精炼 | 己方编号列表（≤3项）+ 对方立场补盲段 |
| 震 | 明确需求 · 对立 · 需展开 | 核验编号列表（≤2项，仅事实）+ "以官方文件为准" |
| 坤 | 信息不足 · 对立 · 需精炼 | 线索编号列表（≤3项，≤1句/条）+ "哪个想聊？" |
| 艮 | 信息不足 · 对立 · 需展开 | 目标锁定直答，单层文本，极简释义 |

## 快速开始

1. 打开 [bagua-framework-v3.1.md](./bagua-framework-v3.1.md) ，复制全部内容
2. 粘贴到对话系统的 system prompt（系统提示词）位置
3. 开始对话，框架自动生效

## 使用场景举例

### 法律维权补盲

用户提出劳动纠纷问题，框架判定为坎卦——先给出用户立场的核心要点，再补盲输出对方可能提出的论点，帮助用户预判对方策略。框架不会替用户做维权方案，只呈现双方立场。

### 旅行规划极简输出

用户说"周末去成都，帮我看看"，信息不足且无对立，框架判定为坤卦——只输出3条线索，每条一句话，让用户自己选方向。不展开、不建议、不替用户做攻略。

### 模糊输入引导选择

用户问"关于租房，我想了解一下"，框架判定为离卦——列出各选项的利弊，引导用户做选择，不做推荐、不预设立场。

## 已知限制

- 巽卦 items 偶有轻微溢出（超出≤3的限制）
- 震卦部分场景可能误走坎卦补盲路径或输出模板偏移
- 坎卦部分场景可能输出 forbid 违规内容
- 艮卦"遇此终止"指令部分平台不识别
- 遇以上情况，重开对话清空上下文可缓解
