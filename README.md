# 八卦检索框架 V3.1

基于东方八卦认知逻辑的检索行为控制框架——复制提示词，粘贴到系统提示词，即可使用。

## 框架速览

| 卦名 | 触发场景 | 输出格式 |
|------|---------|---------|
| 乾 | 明确需求 · 同向 · 需精炼 | 编号列表（≤3项）+ 简短理由 |
| 兑 | 明确需求 · 同向 · 需展开 | 编号列表（≤3项，depth=1）+ "选择：A/B/C？" |
| 巽 | 信息不足 · 同向 · 需精炼 | 编号列表（≤3项，原始信息直出） |
| 离 | 信息不足 · 同向 · 需展开 | 选项利弊分析 + "选择：A/B/C？" |
| 坎 | 明确需求 · 对立 · 需精炼 | 己方编号列表（≤3项）+ 对方立场补盲段 |
| 震 | 明确需求 · 对立 · 需展开 | 核验编号列表（≤2项，仅事实）+ "以官方文件为准" |
| 坤 | 信息不足 · 对立 · 需精炼 | 线索编号列表（≤3项，≤1句/条）+ "哪个想聊？" |
| 艮 | 信息不足 · 对立 · 需展开 | 目标锁定直答，单层文本，极简释义 |
